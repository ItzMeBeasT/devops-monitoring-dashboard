# DevOps Monitoring Dashboard

A beginner-friendly DevOps project to learn monitoring and observability tools by building a real-time infrastructure monitoring dashboard.

## Goals

* Learn Linux administration
* Learn Docker and containerization
* Learn Prometheus and Grafana
* Monitor system and container metrics
* Build a production-style DevOps project

## Tech Stack

* Linux (Fedora)
* Git & GitHub
* Docker
* Prometheus
* Grafana
* Node Exporter
* cAdvisor
